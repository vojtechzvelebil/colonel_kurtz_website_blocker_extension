Have you ever considered any real freedoms? Freedom from watching youtube... Even from checking social media for hours?

If you did, this extension might help you attain them. It lets you stay on websites you restrict, but if you go over your custom set time limit, Kurtz's villainous yellow head will start popping out of the dark to nudge you off.
